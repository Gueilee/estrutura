# Organograma — Gestão de Projetos e TI · Vendemmia

Página estática do organograma da área de Gestão de Projetos e TI da Vendemmia, publicada via GitHub Pages.

## Como acessar

https://gueilee.github.io/estrutura/

## Sobre as edições

O card de cada pessoa (clicando nas caixas do organograma) pode ser editado — nome, cargo, local, descrição do cargo e atividades. As alterações são salvas no `localStorage` do navegador de quem edita, ou seja, **ficam apenas no navegador/dispositivo de quem fez a edição** e não são compartilhadas automaticamente com outras pessoas que acessem o link.

Para atualizar o conteúdo para todos, edite o arquivo `index.html` e publique uma nova versão neste repositório.
